🔮 Politique de Confidentialité - CARTA

Dernière mise à jour : 30 novembre 2024

En bref : CARTA respecte votre vie privée. Aucune donnée personnelle n'est collectée, stockée ou partagée.

1. Informations que nous collectons

Aucune donnée personnelle n'est collectée.

L'application CARTA fonctionne entièrement en local sur votre appareil. Nous ne collectons, ne stockons et ne transmettons aucune information personnelle identifiable.

2. Données stockées localement

Les seules données sauvegardées sont :

  • Historique de tirage : Vos derniers tirages de cartes sont sauvegardés localement sur votre appareil pour vous permettre de les consulter ultérieurement.
  • Préférences : Votre langue préférée et vos paramètres d'application.
  • Cooldown : La date de votre dernier tirage pour gérer le délai de 5 minutes.

Important : Ces données restent sur votre appareil et ne sont jamais envoyées à des serveurs externes.

3. Utilisation d'Internet

L'application se connecte à Internet uniquement pour :

  • Interprétations AI : Lorsque vous demandez une interprétation complémentaire de vos cartes, nous utilisons l'API Google Gemini. Seules les cartes tirées et votre signe astrologique sont envoyés (aucune donnée personnelle).

Vous pouvez utiliser CARTA hors ligne. Les interprétations de base sont disponibles sans connexion Internet.

4. Services tiers

CARTA utilise les services suivants :

  • Google Gemini API : Pour générer des interprétations personnalisées. Politique de confidentialité : https://policies.google.com/privacy

5. Publicités (À venir)

Dans une future version, CARTA pourrait afficher des publicités via Google AdMob. AdMob peut collecter certaines données pour personnaliser les annonces. Vous pourrez consulter la politique de confidentialité d'AdMob ici : https://policies.google.com/privacy

6. Sécurité

Puisque aucune donnée personnelle n'est collectée ou transmise, il n'y a aucun risque de fuite de données personnelles.

7. Vos droits

Vous avez le contrôle total sur vos données locales. Vous pouvez à tout moment :

  • Désinstaller l'application pour effacer toutes les données locales
  • Utiliser l'application hors ligne pour éviter toute connexion Internet

8. Modifications de cette politique

Nous pouvons mettre à jour cette politique de confidentialité occasionnellement. La date de dernière mise à jour sera toujours indiquée en haut de cette page.
